# ハッカソン提出用 CM動画 構成案（Sikurepi）

- **形式**: 16:9 横動画 / 1920×1080
- **尺**: 1分50秒（規定「2分以内」に対して10秒の余裕）
- **型**: 物語ではなく、機能を並べる商品CM。1ブロック＝1機能＝1メッセージ
- **トーン**: 明るい。白〜クリーム基調（アプリのUIに合わせる）。BGMは軽快。カットは短くテンポよく

テロップの数値（自炊回数のしきい値、図鑑の種類数など）は未確定のため入れていない。確定後に差し込む。

---

## 1. 飽きさせ方の設計 ＝「動きの種類」を変える

機能紹介を並べると単調になるが、原因はレイアウトより**動きが同じこと**。ブロックごとに違う動詞を割り当て、同じ動きを2回使わない。

| ブロック | 機能 | 動きの種類 |
| --- | --- | --- |
| B1 | レシートスキャン | **弾ける** — レシートから食材が飛び散る |
| B2 | 食材レスキュー | **手を挙げる** — 奥の食材が揺れて前に出る |
| B3 | AIレシピ | **吸い込まれる** — 散らばった食材が鍋に集まる |
| B4 | 気候連動 | **入れ替わる** — 温度が動くと料理が差し替わる |
| B5 | 週間献立 | **埋まる（順番に）** — マスが次々パタパタ |
| B6 | クッキングモード | **流れる** — 手順カードが横に送られる |
| B7 | キッチン図鑑 | **染まる（波紋状に）** — グレーのマスが色づく |
| B8 | 10段階ランク | **降りる** — 矢印が上から下へ |

画面構成もこれに合わせて変わる。全画面で演出するブロック（B3・B5・B7・B8）と、スマホ＋横テキストのブロック（B1・B2・B6）を交互に置く。スマホ＋テキストは連続させない。

## 3. 各ブロックの中身

### B0 オープニング（5秒）

- **画面**: 白背景。中央にロゴ `[public/main.png]`、右下にシェフぐま `[public/mascot/bear_wave.png]`
- **動き**: ロゴが小さく弾んで着地。同時に食材アイコンが放射状に散って画面外へ抜ける
- **コピー**: ロゴ下に「冷蔵庫から、今日の一皿へ」
- **音**: ポン＋キラキラ。ここでBGMが入る

### B1 レシートスキャン（12秒）— 弾ける

- **画面構成**: 左にコピー、右にスマホ（縦持ち・画面高の75%）
- **動き**:
  1. 画面右上からレシートがひらりと落ちてくる
  2. スキャンの光が上から下へ走る
  3. レシートから食材アイコンが**ぱっと弾け飛ぶ**（10個くらい、放物線を描いて）
  4. 弾けた食材が右のスマホ画面に吸い込まれ、在庫リストとして整列する
- **コピー**: 大「レシートを撮るだけ。」／小「食材はぜんぶ、在庫になる。」
- **音**: シャッター → 弾ける音 → 整列する軽い連続音

### B2 食材レスキュー（10秒）— 手を挙げる

- **画面構成**: 左にスマホ、右にコピー（B1の左右反転）
- **動き**:
  1. 左に冷蔵庫の中のイラスト。食材が何段にも並んでいる
  2. 奥のほうのなすが小さく揺れて、頭の上に「！」が出る
  3. スマホに通知カードがポンと出る（実装の文言をそのまま使う：「冷蔵庫で◯日待っている△△を、今日の主役にしませんか？」）
  4. なすが手前にすっと出てくる
- **コピー**: 大「忘れてた食材、アプリが教えてくれる。」
- **音**: 通知音

### B3 AIレシピ（12秒）— 吸い込まれる

- **画面構成**: 全画面演出 → 最後にスマホがせり上がる
- **動き**:
  1. 画面いっぱいに食材アイコンが散らばっている（20個くらい）
  2. 中央に鍋を持ったシェフぐま `[public/animations/bear-mixing.webp]`
  3. 食材が渦を巻いて**鍋に吸い込まれていく**
  4. 鍋が光る → 料理アイコンがドンと飛び出す `[public/dishes/icons/]`
  5. その料理アイコンが縮んで、下からせり上がったスマホのレシピ画面に収まる
- **コピー**: 上部センター・大きく「在庫から、AIが今日の一皿。」
- **音**: 吸い込む音 → ポン → 完成音

### B4 気候連動（10秒）— 入れ替わる

- **画面構成**: 左右分割。中央に温度計
- **動き**:
  1. 中央の温度計が 33℃ を指している。背景の左半分は暑い日の色（赤〜オレンジ）
  2. 左に「さっぱり系」の料理カード
  3. 温度計の目盛りが**すーっと下がって 4℃** へ。背景が青に変わる
  4. 料理カードが入れ替わって「鍋」になる
- **コピー**: 「暑い日と寒い日で、提案が変わる。」
- **音**: 温度が下がる音（グリッサンド）

### B5 週間献立（10秒）— 埋まる

- **画面構成**: 全画面グリッド → 縮んでスマホに収まる
- **動き**:
  1. 画面いっぱいに 7列×3行の空のマス
  2. 左上から順にパタパタと**料理アイコンが落ちて埋まっていく**（テンポよく、加速させる）
  3. 全部埋まったらグリッド全体が縮んで、スマホの献立画面にそのまま収まる
- **コピー**: 「1週間ぶん、まとめて。」
- **音**: カードめくり音の連打

### B6 クッキングモード（9秒）— 流れる

- **画面構成**: スマホのUIを大写し（枠なし）。実写の指が入る
- **動き**:
  1. 手順カードが指のスワイプで横に3枚流れる
  2. 「困った」をタップ → 「味が濃い」を選ぶ → リカバリの答えがポンと出る
- **コピー**: 画面下に「作ってる最中の『困った』にも。」
- **音**: スワイプ音、タップ音

### B7 キッチン図鑑（10秒）— 染まる

- **画面構成**: 全画面グリッド
- **動き**:
  1. グレーの食材アイコンがびっしり並んだグリッド（画面いっぱい）
  2. 左上の1マスがカラーに光る → そこから**波紋状に色が広がっていく**
  3. 完成率のカウンターが上がる（数値は後で確定）
- **コピー**: 「使った食材が、図鑑に増えていく。」
- **音**: 光る音の重なり

### B8 10段階ランク（22秒）— 降りる

本編の山。アプリに「ランク一覧画面」は無い（ホームのバッジは現在ランク1つだけを描画する実装）ので、このブロックは別に作る。素材は `public/ranks/` の10枚をそのまま使う。

- **画面構成**: 黒背景。バッジ列は画面の左3分の1、ランク名は右3分の2
- **動き**:
  1. バッジ10個が画面中央に縦一列で並ぶ。最初はシルエット。上から順に実像へ切り替わる
  2. 列全体が**左へスライド**
  3. 空いた右側に、各バッジの高さに合わせてランク名が順に出る（Commis / Premier Commis / Garde-Manger / Poissonnier / Rôtisseur / Saucier / Aboyer / Sous-Chef / Chef de Cuisine / Chef Exécutif）
  4. バッジ列の左脇に光の矢印が現れ、**上から下へ降りる**。通過したバッジが一瞬光ってチェックが付く。下へ行くほど減速させる
  5. 最下段の Chef Exécutif に到達。バッジが拡大、放射状の光、紙吹雪
  6. 他のバッジが消えて、白へフェード
- **コピー**: 上部に「10段階のランク！」／矢印が降りている間に「たくさん料理してランクを上げよう！」
- **音**: 打音を10回（1音ずつピッチを上げる）→ 通過音 → 短いファンファーレ → 無音
- **16:9での注意**: 1080pxの高さに10個並べるとバッジ1個あたり85px前後になる。バッジ素材は縦240pxなので縮小はきくが、シルエットが潰れないよう間隔を詰めすぎない。上下に余白を取って、列の高さは800px以内に収める

### B9 締め（10秒）

- **画面**: 白背景。スマホ3台（ホーム／レシピ／図鑑）が扇状に並び、中央に集まってロゴへ
- **コピー**: ロゴ＋「冷蔵庫から、今日の一皿へ」／小さく「日本語・English」「iOS・Android・ブラウザ」／右下にQR
- **音**: BGMがサビ → フェードアウト

## 6. 制作

### アプリ画面（B1・B2・B5・B6の実機部分）

1. `npm run dev` で起動し、Chrome のデバイスモード（iPhone 14 Pro / 393×852 / DPR 3）で表示する
2. データは localStorage が正（`src/lib/storage.ts`）。DevTools のコンソールから在庫・履歴・自炊回数を直接注入してデモ用の状態を作る
3. 60fpsで収録し、編集時にカットごとに速度を変える
4. 16:9に置くときは、収録した縦画面を実機フレーム画像にはめ込む

### 演出部分（B0・B3・B4・B7・B8）

**推奨：HTML/CSSの1枚ページを作ってブラウザを1920×1080で画面収録する。** リポジトリのPNGをそのまま読めて、ランク名やしきい値もコードから引ける。修正が速い。編集ソフトで組むとアイコン数十個の動きを手で付けることになる。

### 仕上げ

- BGMは商用利用可のものを1曲。B0で入れ、B8の到達で一度抜き、B9でフェードアウト
- 字幕は全編に焼き込む。会場で音が出ない前提で作る
